Hand-supplied figure images.

Drop a file named after a figure's slug — `becky-spec-fig-02.png`, say — and the
ingest uses it in place of whatever it would have extracted, including for
figures marked `"skip"` in the manifest. PNG, JPG and JPEG are recognised.

This exists for figures the extractor cannot produce, such as the spec's
"LAYOUT OF BECKY" drawing, which Word stores as a Windows Enhanced Metafile.
